Ende is versioned with [ChronVer](https://chronver.org): each release is named
after the day it's cut, such as `2026.10.17`. There is no fixed schedule;
releases ship when there is something to release.

Releases can be found on the
[GitHub releases page](https://github.com/theende/ende/releases), and
`https://dl.ende.sh/release-latest.txt` names the newest one. Upgrade with
`ende upgrade`, or install a specific release with `ende upgrade <version>`.
